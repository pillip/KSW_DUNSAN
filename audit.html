둔산 노후계획도시 정비 — 행정사무감사 질의 도우미

집행부가 공식 문서와 발표에서 약속한 일정을 추적하고, 트래커 데이터의 숫자를 근거로 질의 항목을 고르면 질의서 초안이 조립됩니다. 업무보고·회의록 PDF를 넣으면 예산 집행과 "검토하겠다"류 약속 문장을 찾아냅니다. 모든 처리는 브라우저 안에서 이뤄지고, 서버로 보내는 것은 없습니다.

감사 기간 2026.11.6 ~ 11.17 (12일) 대상 대전시·교육청·직속기관 등 66개 기관 소관 산업건설위원회 → 도시주택국 (도시계획과 · 지구단위계획팀) 자료요구 상임위별 1,287건 · 시민제보 10월 말까지

집행부 약속·일정 추적

기본계획(안)·FAQ·보도에서 대전시가 밝힌 약속과 기한입니다. 상태와 확인 내용은 이 브라우저에만 저장됩니다(localStorage). 행감 전후로 "확인됨/지연/미이행"을 갱신하세요.

질의 항목 빌더

주제를 고르면 오른쪽에 질의서 초안이 조립됩니다. 숫자는 data.js와 기본계획(안)·FAQ에서 가져온 것이고, 괄호 안이 출처입니다. 초안을 고친 뒤 복사하거나 파일로 저장하세요.

업무보고·회의록 분석

도시주택국 업무보고, 예산서, 지난 회기 회의록 PDF를 올리거나 본문을 붙여 넣으세요. 브라우저 안에서 텍스트를 뽑아 (1) 예산·집행·이월·불용 숫자가 있는 줄, (2) "검토하겠다·추진 예정·연내" 같은 약속 표현, (3) 노후계획도시 관련 문장을 찾습니다. 찾은 약속은 위 추적표에 추가할 수 있습니다.

AI 초안 (선택)

본인의 Claude API 키를 넣으면 선택한 질의 항목, 추적표, 분석 결과를 묶어 질의서 초안을 생성합니다. 키는 이 브라우저의 localStorage에만 저장되고 Anthropic API로 직접 호출합니다(이 사이트의 서버는 없습니다). 키가 없어도 위 빌더는 그대로 쓸 수 있습니다.

생성 결과는 초안입니다. 숫자와 출처는 빌더의 근거 목록과 대조하세요. 외부 API 호출이므로 업무보고에 비공개 정보가 있으면 넣지 마세요.
